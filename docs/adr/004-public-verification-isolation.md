# ADR 004: Public Verification Isolation & Zero-PII Digital Projection

## الحالة (Status)
معتمد (Accepted) — تاريخ: سبتمبر 2026

## السياق (Context)
تحتاج الجامعات لتمكين أصحاب العمل والسفارات والجهات الرسمية من مسح الـ QR للتحقق من صحة شهادات التخرج، دون فتح بوابة لاختراق الخصوصية أو كشف الأرقام القومية وسجلات العلامات والملاحظات الداخلية للطلاب.

## القرار (Decision)
عزل منظومة التحقق العامة بالكامل وفق المعايير التالية:
1. **الرموز المعتمة (Opaque High-Entropy Tokens)**:
   - توليد رموز بطول 12-16 حرفاً بصيغة Crockford Base32 الخالية من الأحرف المتشابهة (`I`, `L`, `O`, `U`).
   - الـ QR Code لا يحتوي أي بيانات للطالب؛ بل يحتوي فقط رابط التحقق المعتم.
2. **الإسقاط الرقمي بالحد الأدنى (Server-Side Public Projection)**:
   - استخراج حقول التحقق الأساسية فقط (اسم الخريج المقنع جزئياً، الدرجة العلمية، الكلية، وسنة التخرج).
   - حظر تصدير أي معرّفات لقاعدة البيانات، أو أرقام هواتف، أو أرقام قومية، أو سجلات علامات.
3. **عزل الواجهة (Separate Trust Boundary)**:
   - تشغيل بوابة التحقق في مسار مستقل تماماً `/public/verify` و `/v/[code]` دون تحميل تطبيق إدارة سهم (Admin Shell).
4. **كشف التخمين ومحدد التدفق (Rate Limiting & Abuse Detection)**:
   - تحديد عدد الطلبات المسموحة وعزل الـ IP في حال تكرار محاولات التخمين.
