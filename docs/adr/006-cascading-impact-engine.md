# ADR 006: Cascading Impact Engine & Stale Artifact Governance

## الحالة (Status)
معتمد (Accepted) — تاريخ: سبتمبر 2026

## السياق (Context)
في العمل الجامعي، قد يُصحح اسم طالب أو يُعدل رقمه الجامعي بعد صدور كشف التخرج الرسمي بصيغة PDF أو بعد استخراج وثيقة التصدير أو بعد إصدار رمز التحقق. إذا تم التعديل بصمت دون تنبيه النظام، ستظل الوثائق السابقة متداولة ببيانات قديمة أو متناقضة مع السجل الرسمي.

## القرار (Decision)
بناء محرك التأثير التعاقبي **Cascade Impact Engine**:
1. **التقييم التعاقبي المسبق (Impact Assessment)**:
   - عند طلب تعديل أي سجل طالب أو شهادة، يفحص المحرك فورياً جميع المنشورات، ومشاريع التصدير (PDF/XLSX)، ورموز التحقق النشطة.
2. **كشف القطع الأثرية القديمة (Stale Artifact Detection)**:
   - وسم أي مستند تصدير سابق بأنه قديم (`is_superseded = True`) مع إظهار تنبيه مؤسسي صريح للمستخدم:
     > *"This export was generated from an older dataset version."*
3. **منع التعديل الصامت (Zero Silent Mutation)**:
   - إلزام المراجع أو المدير بكتابة سبب رسمي معتمد وتوثيق المرجع الإثباتي لكل تصحيح.
   - إصدار حدث تدقيق رسمي (Audit Event) وتحديث إصدار السجل (Version Numbering).
