# تفكيك التعارضات والمطابقة الآمنة عند استلام الحزم
## Conflict Taxonomy, Reconciliation Policies & Safe Merge

---

## 1. مبدأ عدم الكتابة فوق البيانات بصمت (No Silent Overwrite)

> **"Never use Last-Write-Wins for official university records."**

عند استلام حزمة عمل جديدة في مساحة عمل تحتوي بالفعل على سجلات سابقة، يرفض النظام تطبيق قاعدة "الأحدث يلغي الأقدم" تلقائياً. بدلاً من ذلك، يُجري النظام **فحص مقارنة تفصيلي (Diff Analysis)** ويصنف الفروقات وفق مصفوفة تعارضات دقيقة.

---

## 2. أصناف التعارضات المؤسسية (Conflict Classes)

```text
┌───────────────────────┬────────────────────────────────────────────────────────┐
│ صنف التعارض           │ الوصف والحالة الميدانية                                 │
├───────────────────────┼────────────────────────────────────────────────────────┤
│ DATA_CONFLICT         │ اختلاف قيمة حقل رسمي (مثل: تاريخ التخرج 2024 vs 2023)  │
├───────────────────────┼────────────────────────────────────────────────────────┤
│ STATE_CONFLICT        │ تباين حالة الشهادة (مثل: Local = Approved vs Incoming   │
│                       │ = Needs Review)                                        │
├───────────────────────┼────────────────────────────────────────────────────────┤
│ OWNERSHIP_CONFLICT    │ تعارض المالك التشغيلي أو محاولة انتزاع مهمة محجوزة     │
├───────────────────────┼────────────────────────────────────────────────────────┤
│ VERSION_CONFLICT      │ الحزمة مبنية على إصدار قديم من مخطط البيانات (Schema)  │
├───────────────────────┼────────────────────────────────────────────────────────┤
│ SOURCE_CONFLICT       │ تباين في صورة المصدر أو بصمة الهاش لنفس رقم الشهادة    │
├───────────────────────┼────────────────────────────────────────────────────────┤
│ PROVENANCE_CONFLICT   │ تضارب في هوية منشئ السجل الأصلي أو تاريخ المسح الأول   │
└───────────────────────┴────────────────────────────────────────────────────────┘
```

## 3. استراتيجيات الحل والدمج المعتمدة (Merge Strategies)

### 3.1 الدمج الآمن على مستوى الحقول (Field-Level Merge)
إذا كانت الحقول المعدلة مستقلة وغير متضاربة:
- **المحلي (Local)**: قام بتحديث اسم الكلية فقط (ولم يمس تاريخ التخرج).
- **القادم (Incoming)**: قام بتحديث تاريخ التخرج فقط (ولم يمس اسم الكلية).
- **النتيجة**: دمج تلقائي سليم لعدم وجود تعارض في نفس الحقل.

### 3.2 الاحتفاظ بالنسخة المحلية (KEEP_LOCAL)
- تجاهل التعديل الوارد والإبقاء على القيمة الحالية المعتمدة محلياً مع تسجيل سبب الرفض في سجل التدقيق.

### 3.3 اعتماد النسخة القادمة (KEEP_INCOMING)
- استبدال القيمة المحلية بالواردة بشرط توفر الصلاحية الإدارية وتوثيق الفاعل.

### 3.4 المراجعة اليدوية المتخصصة (MANUAL_REVIEW)
- عزل السجلات المتعارضة في طابور مراجعة خاص (Conflict Queue) مع إبراز الفروقات بلونين مختلفين (Diff Inspector) ليتخذ المدقق الأكاديمي القرار الصائب.
