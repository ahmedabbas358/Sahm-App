# بروتوكول النقل المباشر بين الأجهزة المتجاورة والمصافحة الأمنية
## Local Direct Device-to-Device Transfer & Mutual Handshake

---

## 1. الدافع والهدف
عندما يكون الموظف (أ) الذي قام بمسح 500 شهادة في نفس المكتب أو الطابق بجانب الموظف (ب)، فإن رفع حزمة بحجم 2 جيجابايت إلى السحابة ثم إعادة تنزيلها يستهلك وقت الموظفين وعرض النطاق الترددي للإنترنت في الجامعة.

يوفر **Sahm Direct Transfer** قناة نقل محلية فائقة السرعة عبر الشبكة المحلية (Local LAN / Wi-Fi Direct) دون المرور بالإنترنت الخارجي، مع الحفاظ الكامل على **الأمان والتشفير والتدقيق**.

---

## 2. بروتوكول المصافحة والمصادقة الثنائية (Mutual Handshake)

لا يسمح النظام بالاتصال التلقائي الصامت بمجرد اكتشاف جهاز في الجوار؛ بل يشترط **تأكيداً بشرياً متبادلاً**:

```text
┌─────────────────────────┐                     ┌─────────────────────────┐
│     Device A (Sender)   │                     │   Device B (Receiver)   │
└────────────┬────────────┘                     └────────────┬────────────┘
             │                                               │
             │  1. إنشاء جلسة نقل وتوليد رمز الاقتران        │
             │     + توليد عبارة التحقق (BLUE-ORBIT-27)      │
             │     + عرض رمز QR مؤقت على الشاشة              │
             │                                               │
             │  2. مسح رمز الـ QR من كاميرا B                │
             ├──────────────────────────────────────────────►│
             │                                               │
             │  3. مصادقة الهوية المؤسسية (mTLS / Session)   │
             │◄─────────────────────────────────────────────►│
             │                                               │
             │  4. عرض شاشة التأكيد المتبادل على الجهازين    │
             │     [تطابق عبارة: BLUE-ORBIT-27]              │
             │     [حجم الحزمة: 1.8 GB - 500 شهادة]          │
             │                                               │
             │  5. موافقة صريحة: [قبول الاستلام]            │
             │◄──────────────────────────────────────────────┤
             │                                               │
             │  6. نقل البيانات المشفرة محلياً (TLS 1.3)    │
             ├══════════════════════════════════════════════►│
             │                                               │
             │  7. التحقق من سلامة البصمة (SHA-256)          │
             │     + تسجيل حدث التسليم في سجل التدقيق        │
             ▼                                               ▼
```

## 3. معايير الأمان الإلزامية في النقل المباشر

1. **التحقق من موثوقية الجهاز (Device Trust Status)**:
   - يجب أن يكون كلا الجهازين مسجلين في المؤسسة كـ `TRUSTED` أو `PENDING_APPROVAL`.
   - يُحظر النقل فوراً إلى أي جهاز في حالة `REVOKED`.
2. **التشفير الإلزامي (In-Transit Encryption)**:
   - كافة الحزم المنقولة محلياً تظل مشفرة بـ TLS 1.3 مع تشفير الحزمة بـ AES-256.
   - لا يتم نقل أي ملف بصيغة نص عادي (Cleartext) عبر الشبكة المحلية.
3. **عبارة التحقق البشرية (Visual Verification Phrase)**:
   - تتكون من صفتين واسم ورقم (مثل: `BLUE-ORBIT-27` أو `SWIFT-SHADOW-42`).
   - تحمي بنسبة 100% من هجمات انتحال الشخصية أو الرجل في المنتصف (Man-in-the-Middle) على الشبكة المحلية.
